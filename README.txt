# ExpenseEase – Personal Expense Tracker

## 1. Project Overview

ExpenseEase is a Python-based desktop application designed to record, manage, and analyze personal expenses.

## 2. Technologies Used

* Python
* Tkinter for the graphical user interface
* NumPy for numerical calculations
* Pandas for expense data management and analysis
* Matplotlib for data visualization
* CSV for storing expense records

## 3. Main Features

* Add expense records
* View recorded expenses
* Delete selected expenses
* Calculate total, average, highest, and lowest expenses
* Calculate standard deviation
* Visualize expenses using pie charts and bar charts
* Save expense records in a CSV file

## 4. Project Files

* expense_ease.py: Main Python application
* expenses.csv: Expense records
* Screenshots: Application interface, charts, and source-code screenshots
* Reference_Report.pdf: Reference document for report preparation
* Project_Prompt.txt: Instructions for preparing the project report

## 5. Software Requirements

* Windows operating system
* Python 3
* Visual Studio Code
* Tkinter
* NumPy
* Pandas
* Matplotlib

## 6. How to Run

1. Open the project folder in Visual Studio Code.

2. Open the integrated terminal.

3. Navigate to the folder containing expense_ease.py.

4. Run the following command:

   python expense_ease.py

5. The ExpenseEase application window should open.

## 7. Data Storage

Expense records are stored in expenses.csv. Keep the CSV file in the appropriate project directory when running the application.

## 8. Academic Purpose

This project demonstrates Python programming, object-oriented programming, GUI development, data handling, numerical calculations, and data visualization.
